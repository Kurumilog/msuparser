# 🚀 Локальный запуск проекта

## Шаг 1: Установка зависимостей

```bash
# Убедитесь, что Go установлен (версия 1.21+)
go version

# Установите зависимости
go get github.com/PuerkitoBio/goquery
go mod tidy
```

## Шаг 2: Настройка конфигурации

```bash
# Скопируйте пример конфигурации
cp config.example.json config.json

# Отредактируйте config.json
nano config.json
```

В `config.json` укажите:
- `BOT_TOKEN` — токен вашего Telegram бота от [@BotFather](https://t.me/BotFather)
- `USER_ID` — ваш Telegram ID (получите через [@userinfobot](https://t.me/userinfobot))
- `NOTIFICATION_MINUTES` — за сколько минут присылать уведомления до пары (рекомендуется 15)

## Шаг 3: Тестирование и сборка проекта

```bash
# Запуск автотестов
go test -v .

# Собрать основной бот
go build -o main main.go parser.go gifs.go changes.go

# Собрать автономный парсер (для тестов/первичного дампа)
go build -o test_parser test_parser.go parser.go
```

Или используйте Makefile:

```bash
make test-unit    # Запуск автотестов
make all          # Сборка бота и парсера
```

## Шаг 4: Запуск

### 1. Получить первичное расписание (опционально)

```bash
./test_parser
```

Это создаст файл `schedule.json` с актуальным расписанием на 14 дней.

### 2. Запустить бота

```bash
./main
```

Бот будет:
- **Уведомлять перед парами**: за 15 минут до начала (для 3-й пары — за 45 минут).
- **Постоянно индексировать расписание**: бот каждые 15 минут днем (07:00–23:00 МСК) и раз в час ночью проверяет сайт `tt.audit.msu.ru`. При обнаружении добавлений, отмен или переносов занятий на ближайшие 7 дней бот немедленно присылает детальное push-сообщение.
- **Присылать утреннее напоминание в 08:00**: список пар на день с аудиториями и преподавателями (настраивается в `/settings` с выбором «Дистант» и «Очно»).
- **Работать с командами**:
  - `/schedule` — интерактивный просмотр расписания с кнопками «Назад / Вперед».
  - `/next` — ближайшая пара и время до неё.
  - `/gifs` — добавление и привязка персональных гифок/видео/стикеров к событиям.
  - `/settings` — настройки времени утренних/вечерних сводок, напоминания о парах и ручной парсинг.

## 🔧 Полезные команды

```bash
# Пересобрать всё
make clean && make all

# Проверить код линтером и тестами
make lint
go test -v .

# Запустить бота в фоне
nohup ./main > logs/bot.log 2>&1 &

# Посмотреть логи
tail -f logs/bot.log

# Остановить бота
pkill -f "./main"
```

## 🐛 Решение проблем

### Ошибка "command not found: go"
Установите Go с https://go.dev/dl/

### Ошибка "cannot find package goquery"
```bash
go get -u github.com/PuerkitoBio/goquery
go mod tidy
```

### Не приходят уведомления
1. Проверьте, что `BOT_TOKEN` и `USER_ID` в `config.json` заполнены верно.
2. Убедитесь, что вы написали боту `/start` в Telegram.
3. Проверьте, что `schedule.json` существует и содержит занятия.

### schedule.json пустой
Проверьте доступность сайта https://tt.audit.msu.ru/ из вашей сети.
