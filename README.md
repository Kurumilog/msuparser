# 🎓 MSU Timetable Bot

Автоматизированная система мониторинга расписания занятий МГУ ВШГА (группа 303) с постоянной индексацией изменений и персонализированными уведомлениями в Telegram.

---

## 📋 Основные возможности

- ⚡ **Нативный Go-парсер**: прямой HTTP-парсинг сайта `tt.audit.msu.ru` без внешних браузерных драйверов и Selenium. Время парсинга — 1–3 секунды, потребление памяти — ~20–40 МБ.
- 🔄 **Постоянная индексация расписания**: бот автоматически проверяет сайт каждые 15 минут днем (07:00–23:00 МСК) и раз в час ночью.
- 📢 **Push-уведомления об изменениях**:
  - Распознавание добавленных (`🟥`), отмененных (`🟩`) и перенесенных (`🔄`) пар.
  - Поддержка переносов между днями недели.
  - Отслеживание замен предметов в слоте, изменений аудиторий и преподавателей.
  - Красивое моноширинное форматирование времени (`1 пара 09:00–10:30`), аудитории курсивом.
- ⏰ **Утреннее напоминание в 08:00**:
  - Присылает список пар на текущий день с номерами, временем, предметами, аудиториями и преподавателями.
  - Настраивается прямо в боте через `/settings`: галочки **«Дистант»** и **«Очно»**.
- 🔔 **Уведомления перед занятиями**:
  - За 15 минут до начала пары.
  - Для 3-й пары — за 45 минут (после обеденного перерыва).
- 🖼 **Персональные гифки и медиа**:
  - Система слотов: `🌅 Утро`, `🌙 Вечер`, `🔔 Уведомления`, `📱 Команды`.
  - Загрузка гифок, стикеров и видео прямо через чат бота (`/gifs`).
  - Настраиваемое время утренних и вечерних приветствий со сводкой пар.
- 🧪 **100% покрытие ключевой логики автотестами**: тесты диффа, переносов, парсинга и сценариев отправки (`go test -v .`).

## 🤖 Команды бота

| Команда | Описание |
|---|---|
| `/schedule` | Интерактивное расписание на день с кнопками пагинации «⬅️ Назад» и «Вперед ➡️» |
| `/next` | Информация о ближайшей паре и таймер обратного отсчета до неё |
| `/gifs` | Меню управления персональными гифками (добавление, просмотр, удаление, привязка к слотам) |
| `/settings` | Настройка времени утренних/вечерних сообщений, галочек напоминаний («Дистант»/«Очно») и кнопка ручного парсинга |
| `/start` | Приветствие и проверка Telegram ID |

## 🚀 Быстрый старт локально

### 1. Требования

- Go 1.21+ (рекомендуется 1.24+)
- Telegram-токен бота от [@BotFather](https://t.me/BotFather)

### 2. Клонирование и настройка

```bash
git clone https://github.com/Kurumilog/msuparser.git
cd msuparser

# Установка зависимостей
go get github.com/PuerkitoBio/goquery
go mod tidy

# Настройка конфигурации
cp config.example.json config.json
nano config.json
```

Пример `config.json`:
```json
{
  "BOT_TOKEN": "123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ",
  "USER_ID": "6194786422",
  "NOTIFICATION_MINUTES": 15
}
```

### 3. Запуск тестов и сборка

```bash
# Запуск автотестов
go test -v .

# Сборка бота
go build -o main main.go parser.go gifs.go changes.go

# Сборка вспомогательного CLI парсера
go build -o test_parser test_parser.go parser.go
```

Или через `Makefile`:
```bash
make all
```

### 4. Запуск

```bash
# Получить первичное расписание
./test_parser

# Запустить бота
./main
```

## 🌐 Развертывание на сервере

Подробная пошаговая инструкция с безопасным обновлением и настройкой systemd доступна в файле:
👉 **[DEPLOY_GUIDE.md](DEPLOY_GUIDE.md)**

Кратко:
1. Загрузите файлы на сервер через `scp`:
   ```bash
   scp main.go gifs.go parser.go changes.go test_parser.go Makefile deploy.sh root@server-ip:/root/msuparser/
   ```
2. Соберите и запустите через systemd:
   ```bash
   go build -o main main.go parser.go gifs.go changes.go
   systemctl restart msuparser-bot
   ```
